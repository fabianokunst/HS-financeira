Como usamos os dados coletados

Os dados coletados são utilizados pela Instituição para atingir finalidades específicas e limitadas. As informações podem ser utilizadas para completar o cadastro ou verificar as informações que o cliente forneceu, com o objetivo de melhorar o cadastro e a experiência, prevenir fraudes e cumprir obrigações legais.

A Instituição utiliza os dados para processar as solicitações, desenvolver e melhorar seus produtos e serviços e, desde que autorizado pelo cliente, para oferecer produtos, publicidade e comunicações personalizadas.
